Setup, checks, and commit rules are in [docs/source/development.rst](docs/source/development.rst). Commit messages and PR titles follow Conventional Commits.

## Architecture decisions

Decisions live in [docs/adr](docs/adr/README.md).

* Read the ADRs relevant to an area before changing it.
* For a significant decision, add an ADR from [the template](docs/adr/template.md) and update the index.
* Never edit an accepted ADR's decision. Write a new ADR and mark the old one `Superseded by`.
